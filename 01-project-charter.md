# Project Charter

## OrangeHRM Manual QA Testing

Version: 1.0

Status: Approved

Date: 27/07/2026

---

## 1. Project Purpose

The purpose of this project is to perform manual functional testing on the OrangeHRM Demo application, simulating the workflow of a professional QA team from project kickoff to final reporting.

---

## 2. Project Objective

Validate that the selected OrangeHRM modules satisfy the defined functional requirements and provide the expected behavior for end users.

---

## 3. Scope

Modules included:

- Login
- PIM
- Leave

Expected validations:

### Login

- Successful login
- Invalid login
- Required field validations
- Error messages

### PIM

- Search employees
- View employee information
- Register new employees
- Edit employee information
- Validate success and error messages

### Leave

- View leave requests
- Create leave requests
- Approve or reject requests (when available)
- Validate displayed information

---

## 4. Out of Scope

Modules excluded:

- Recruitment
- Performance
- Time
- Payroll
- Admin
- Maintenance
- Buzz

Testing excluded:

- API Testing
- Automation Testing
- Performance Testing
- Security Testing
- Mobile Testing
- Database Validation

---

## 5. Test Environment

Application:

OrangeHRM Demo

Browsers:

- Google Chrome
- Microsoft Edge

User:

Administrator

---

## 6. Deliverables

- Project Charter
- Scope
- Functional Analysis
- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Report
- Bug Reports
- Test Evidence
- Final Report

---

## 7. Working Methodology

Workflow:

1. Kickoff
2. Functional Analysis
3. Scope
4. Test Planning
5. Test Scenarios
6. Test Cases
7. Test Execution
8. Bug Reporting
9. Final Report

Project management will be handled in Jira.

Version control will be managed in GitHub.

---

## 8. Success Criteria

The project will be considered completed when:

- Documentation is finished.
- Planned test cases have been executed.
- Bugs are documented.
- Final report has been completed.
- Repository reflects a professional QA workflow.
