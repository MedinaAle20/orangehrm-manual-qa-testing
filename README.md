# OrangeHRM Manual QA Testing

Manual QA portfolio project for planning the functional validation of selected modules in the OrangeHRM demo application.

## Project status

**In development — insufficient execution evidence for a complete portfolio case study.**

The repository currently documents the project charter and intended scope. Test scenarios, test cases, traceability, execution results, defects and screenshots have not yet been added. No test execution or defect discovery is claimed.

## Scope

The existing charter defines the following modules:

- **Login:** successful and unsuccessful login, required fields and error messages.
- **PIM:** employee search, viewing, registration and editing.
- **Leave:** viewing and creating requests, plus approval or rejection when available.

API, automation, performance, security, mobile and database testing are explicitly outside the current scope.

## QA approach

The planned workflow documented in the charter is:

1. Functional analysis
2. Scope definition
3. Test planning
4. Scenario and test-case design
5. Manual execution
6. Defect reporting
7. Final reporting

Only the initial planning and scope-definition stage is represented in this repository today.
